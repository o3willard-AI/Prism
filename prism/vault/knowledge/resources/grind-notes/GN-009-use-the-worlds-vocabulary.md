# GN-009 — Use the world's vocabulary

**Harvested from:** the delivery-channels decision (Session 1 UI
iteration), when the co-creator confirmed `vault/prompts/` as the
landing place for prepared prompts, stating the principle verbatim:
*"we need to center ourselves on base reality and what the existing
world uses and understands already."*

**The law:** Invent vocabulary only for concepts that genuinely have no
name yet. For everything the world already names — prompt, file, copy,
save, search — use the world's word, not a Prism neologism.

**The test:** *"Does this thing already have a name?"* If yes, use it.
Every invented term is a friction tax paid by every future reader,
human or agent. Base reality is the lowest-friction interface there is.

**Prism's own terms are legitimate where they earn it:** lens, grind,
focal point, emission, scattering — these describe concepts with no
existing name. A prepared prompt is not one of them. The world knows
what a prompt is; calling it "prepared light" in a filename would be
friction dressed as branding.

**Applications:**

- Folder names, filenames, UI labels, and emission fields default to
  world vocabulary.
- When a Prism metaphor and a world word compete for the same referent,
  the world word wins in anything the human or an agent must *read or
  act on*; the metaphor may stay in the docs that explain the design.

**Relation to other laws:** a naming-side companion to the UI friction
law (keep the human inside their own thought) — invented vocabulary is
a decision the reader is forced to make, every time they read it.

**Recommendation surface:** every naming decision — lenses, folders,
files, fields, UI controls, harvest notes.
