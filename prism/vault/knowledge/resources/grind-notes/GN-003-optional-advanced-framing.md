# GN-003 — Offer the advanced framing; never gatekeep

**Harvested from:** Session 1, co-creator's entrance-regime answer (Q2).

**The move:** When a more disciplined framing would sharpen the input
(first-principles decomposition, structured blocks, a named method),
OFFER it as an optional path — never require it. Session 1's exact
phrasing for the lens entrance:

> "Tell me about the thing you want AI to do — fog included. If you're
> familiar with first-principles thinking, try describing it that way.
> If not, no problem, just lay it out for me."

**Why it works:** It trains users toward the sharper pattern without
blocking the ones who don't have it yet. The lens accepts both the raw
and the refined; the invitation quietly teaches. Over many uses, the user
drifts toward first principles on their own.

**The principle:** Prism's job is to raise clarity, not to gatekeep it.
Every entrance and every question should give the human a low floor and
a visible higher rung.

**Reusable move:** When designing any lens entrance or clarifying
question, ask: can I phrase this so the disciplined version is offered
but the plain version is always accepted?

**Recommendation surface:** Every grind session, entrance design (Phase 2,
reception component).
