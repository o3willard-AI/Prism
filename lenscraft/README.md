# lenscraft

Working drafts for the lens-crafting machine — the pivot from "run five
pre-built lenses" to "co-create new lenses on demand."

This directory is the workshop floor. Files here are thinking material,
not yet product surface.

```
00-lens-anatomy.md   What a lens IS — distilled from the existing eight
                     skills + three workflows. The machine's target shape.
01-grind-loop.md     The co-creation dialogue the machine must run:
                     broad-batch questioning, first-principles descent,
                     real-light testing, harvest for generalizability.
02-intelligence-rating.md  Minimum-capability rating for every shelved
                     lens: cognitive demand class (L1–L4, durable) plus a
                     provisional parameter floor; calibrated against the
                     eight reference lenses.
```
